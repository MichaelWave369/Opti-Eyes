# Opti-Eyes Rung 4 / Hardware Research Studio

The studio models six adjustable drawing dimensions in millimeters: lens aperture width (42–60), aperture height (28–52), bridge (14–26), endpiece allowance (6–16), temple reference length (125–155), and illustrative rim width (2–5). Limits are UI constraints only, not qualified measurements, prescription eyewear, verified optical clearance or face-fit data.

Drawing-model front span = 2 × aperture width + bridge + 2 × endpiece. Lens center spacing = aperture width + bridge. Neither number is a clinical pupil-distance measurement. Rendered diagrams are stylized front/side geometry only.

Architecture options are fixed optical inserts (not autofocus), sliding Alvarez-type plates, fluidic variable-curvature, and electrically tunable optics. They list qualitative engineering challenges and tests; there are no assertions of range, throughput, prices, patents cleared, battery performance, or actual prototypes.

Export SVG drawing, JSON design constraints, or basic OpenSCAD front-geometry ring/bridge/endpiece. The SCAD omits wearable temple arms, hinges, real lenses, electrical components and any optical fitting. This design is NON-WEARABLE and NOT SAFE EYEWEAR. Do not wear the printed mockup.

Test with npm run check and npm run build. The existing optical focus lab and pinned Gen.E.Wrist v0.3.0 integration must remain unchanged. Before manufacturing wearable eyewear, seek qualified optical, mechanical, electrical and relevant regulatory review.
